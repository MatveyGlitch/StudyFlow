# 📚 StudyFlow — учебный планировщик

**StudyFlow** — учебное веб-приложение для планирования задач, контроля их выполнения и организации времени. Проект разработан в рамках лабораторной работы №5 по дисциплине **«Web-программирование»** на тему «Основы JavaScript и проектирования компонентов» (**вариант 7**).

Все интерактивные компоненты реализованы на **чистом JavaScript** без сторонних библиотек и фреймворков.

---

## ✨ Возможности сайта

- **Таймер концентрации (№3)** — выбор длительности учебной сессии, запуск, пауза, продолжение и сброс; учёт времени в фокусе.
- **Аккордеон (№5)** — раскрывающиеся разделы с учебными материалами.
- **Форма с валидацией (№9)** — проверка имени, email и пароля с подсветкой полей и сообщениями об ошибках.
- **To-Do список (№10)** — добавление, выполнение и удаление задач, а также очистка выполненных.
- **Прогресс-бар (№13)** — автоматический расчёт доли выполненных задач и визуализация прогресса.
- **Переключатель размера шрифта (№18)** — увеличение, уменьшение и сброс размера текста в заметках.
- **Анимация при наведении (№20)** — интерактивные карточки предметов с CSS-эффектами и обработкой событий JavaScript.

Дополнительно реализованы недельный календарь, текущая дата, навигация по разделам и карточки статистики. Задачи, накопленное время концентрации и выбранный размер шрифта сохраняются в `localStorage`.

## 📄 Разделы сайта

| Раздел | Назначение |
|---|---|
| **Обзор** | Общая статистика, календарь и таймер концентрации |
| **Мои задачи** | Управление учебными задачами |
| **Прогресс** | Отображение процента выполненных задач |
| **Материалы** | Аккордеон с темами веб-разработки |
| **Заметки** | Чтение текста с изменяемым размером шрифта |
| **Предметы** | Анимированные карточки HTML, CSS и JavaScript |
| **Профиль** | Демонстрационная форма с JavaScript-валидацией |

---

## 🛠️ Используемые технологии

- **HTML5** — структура страницы и семантическая разметка.
- **CSS3** — стилизация, градиенты, переходы и адаптивная вёрстка.
- **JavaScript** — обработка событий, работа с DOM и логика компонентов.
- **LocalStorage** — сохранение задач, учебного времени и настройки шрифта.
- **Git / GitHub** — контроль версий и хранение проекта.

Сторонние JavaScript-библиотеки и фреймворки не используются.

## 📁 Структура проекта

```text
lab5-js-components/
├── index.html
├── style.css
├── js/
│   ├── app.js
│   ├── timer.js
│   ├── accordion.js
```

Каждый из семи обязательных компонентов имеет отдельный JS-файл. Файл `app.js` отвечает за общую логику интерфейса, календарь и навигацию.

---

## 📱 Адаптивная вёрстка

Интерфейс адаптирован для компьютеров, планшетов и смартфонов. Используются **CSS Grid**, **Flexbox** и медиазапросы. На небольших экранах боковая навигация преобразуется в горизонтальное меню, а карточки перестраиваются по ширине экрана.

---

## 🎨 Особенности интерфейса

- Светлая рабочая область и фиолетово-синее боковое меню.
- Цветные карточки статистики и градиентный таймер.
- Плавные переходы, эффекты наведения и анимация карточек.
- Динамическое создание элементов To-Do списка через JavaScript.
- Синхронизация статистики и прогресс-бара при изменении задач.

## 🚀 Локальный запуск

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в **PhpStorm**.
3. Открыть `index.html` в браузере через PhpStorm.

Сборка проекта и установка зависимостей не требуются.
